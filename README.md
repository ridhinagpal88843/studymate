
# StudyMate – Smart Study Planner

StudyMate is a responsive, frontend-only study planning website designed to help students organize their academic tasks, manage deadlines, and track their study progress efficiently.

## Features
- Add study tasks with subject names and deadlines.
- Mark tasks as completed.
- Delete tasks when no longer needed.
- Filter tasks by status.
- Track overall study progress with a progress indicator.
- Save tasks automatically using browser LocalStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
1. Download or clone the project repository.
2. Open the `StudyMate` folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.

## Deployment
StudyMate can be deployed independently using Vercel.

- Framework Preset: Other
- Build Command: Leave blank
- Output Directory: `.`

## Project Type
Frontend-only web application. No backend or database is required. Study data is stored locally in the user's browser.
